## Notes

Each laboratory is kept in its own folder so files from different activities remain separated.

### Running the HTML/CSS/JavaScript labs
Open the relevant lab folder and launch its `index.html` file in a browser. Some labs may require opening `dashboard.html` after login.

### Running the Laravel project (Lab 5)
Open a terminal in `lab5_2411600030/inventory-management-main/`, install dependencies with Composer, configure a local `.env` file using `.env.example`, then follow the project's README instructions.

Do not commit real passwords, API keys, private environment files, or production credentials.
